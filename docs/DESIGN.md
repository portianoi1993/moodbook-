# MoodBook — DESIGN.md · «Nocturne» (v3, 5 вересня 2026)

Контракт візуального напряму. Джерела: `docs/SKILLS-AUDIT.md` (усі 232 скіли з вердиктами) і `design-system/moodbook/MASTER.md` (згенеровано ui-ux-pro-max).

## 1. Ідея
Нічна кімната, де книга звучить. Темне кіно-скло, одна брендова пара кольорів (фіолет → бірюза), живе світло за героєм, кнопки, що реагують на руку. Продукт показаний як доказ у першому екрані (картка «книга → треки»), а не описаний словами.

## 2. Кольори
| Токен | Значення | Роль |
|---|---|---|
| `--bg` / `--bg-2` / `--bg-3` | `#07070F` / `#0B0C18` / `#111327` | фон, оболонки, глибші площини (не чистий чорний) |
| `--glass` `--glass-2` `--glass-3` | білий 4 / 7 / 11 % | скляні заливки |
| `--line` `--line-2` `--line-3` | білий 8 / 14 / 22 % | hairline-межі |
| `--text` / `--text-2` / `--text-3` | `#F4F4FA` / `#B9BCD3` / `#7F84A6` | текст, вторинний, мітки (контраст ≥ 4.5:1 для основного) |
| `--violet` / `--violet-2` | `#8B7CFF` / `#6D5DF6` | акцент, активні стани, glow |
| `--teal` | `#2DD4BF` | друга нота градієнта, індикатори «live» |
| `--amber` | `#F5B54A` | лише попередження (ліміт) |
| `--grad` | 135°, violet → violet-2 → teal | CTA Pro, активна сцена, еквалайзер, лого |

Заборонено: теплі «паперові» тони, сірі суцільні бордери, чистий `#000`, третій акцент, градієнти на великих площинах тексту (лише на 1–2 словах заголовка).

## 3. Типографіка
- Display: **Bricolage Grotesque** (opsz 96, wdth 96 у героі), вага 600, трекінг −0.025…−0.04em.
- UI/текст: **Geist** 400–600, 16px/1.55.
- Мітки: **Geist Mono** 0.6–0.7rem, uppercase, трекінг .12–.16em.
- Inter/Roboto/Arial заборонені (soft-skill).

## 4. Поверхні: double-bezel
Кожна важлива картка = зовнішня оболонка `.shell-glass` (glass 4 %, hairline, тінь) + внутрішнє ядро `.core` (темніша заливка, blur 14px, внутрішній хайлайт 1px, радіус на 6px менший). Преміальні поверхні додатково отримують `.gborder` — масковану градієнтну рамку 1px (violet→teal). Наведення на картку вмикає spotlight, що йде за курсором (`[data-spot]`).

## 5. Кнопки
- Primary `.btn`: біла пігулка, текст `--bg`, вкладена кругла іконка-стрілка («button-in-button»), sheen-проліт на hover, магнітне притягання до курсора (clamp 0.22, лише fine pointer), `scale(.97)` при натисканні.
- `.btn.grad`: те саме, але градієнтна заливка з glow — лише для Pro.
- `.btn-glass`: вторинні дії (назад, зберегти, поділитися).
- Іконки без тексту завжди з `aria-label`. Мінімум 44px по дотику.

## 6. Композиція
- Плаваюча island-навігація (glass-пігулка, top 14px). На мобільному — плаваюча нижня пігулка з трьома вкладками.
- Герой: оболонка `.hero-shell` з canvas-атмосферою (4 орби + світлові складки, half-res, пауза поза екраном), Editorial Split 1.15/0.85 на ≥1060px, зразок картки з tilt і плаваючими чипами.
- Стрічка-marquee назв книг з маскованими краями.
- Bento 12 колонок (7/5, 5/7) для «як працює».
- Плани: дві glass-картки, Pro з `.gborder`.
- FAQ: glass-рядки з `<details>`.
- Фінальний CTA у власній оболонці з glow.
- Результати: книга (sticky) + сцени зліва, треки справа; активний трек — градієнтний фон + рамка; док плеєра — glass-пігулка з `.gborder`.

## 7. Рух
- Вхід: `translateY(22px) + blur(8px) → 0` за 0.9s `cubic-bezier(.32,.72,0,1)`, діти зі зсувом `--d`.
- Заголовок героя: слова піднімаються з маски, крок 70 мс.
- UI-стани ≤ 300 мс, лише transform/opacity. Атмосфера й marquee — єдині постійні рухи; пауза при `document.hidden` і поза екраном.
- `prefers-reduced-motion`: усе миттєво, canvas статичний.

## 8. Голос
Коротко, друга особа, конкретика. Заголовки без Title Case. Без знаків оклику в успіху. Помилки з наступним кроком.

## 9. Не робити
Світлі теми, теплі бежеві, серифи, три однакові картки, стокові фото, емодзі як іконки, blur на скролених контейнерах, glow на всьому підряд, більше однієї магнітної кнопки в полі зору.
