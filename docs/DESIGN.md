# MoodBook — DESIGN.md · «Golden Hour Library» (v4, 5 вересня 2026)

Контракт візуального напряму. Історія: v2 «чистий SaaS» → v3 «Reading room» (папір) → «Nocturne» (темне скло) → **v4 «Golden Hour Library»**: власник попросив ламповий книжковий настрій і пастельні різні кольори замість «фінтех/тех»-вигляду. Джерела: `docs/SKILLS-AUDIT.md`, `design-system/moodbook/MASTER.md` (ui-ux-pro-max), soft-skill (Soft Structuralism), orange-clean-paper-saas, blue-cloudy-clean-modern, css-border-gradient, animation-systems, emil-design-eng, marquee-loop, reveal-hover.

## 1. Ідея
Бібліотека о золотій годині: тепле кремове світло, м'які пастельні плями кольору, справжні обкладинки книг як головні герої, рух, що відчувається як дотик, а не як демо технологій.

## 2. Кольори
| Токен | Значення | Роль |
|---|---|---|
| `--cream` / `--cream-2` / `--paper` | `#FBF6EE` / `#F5EDE1` / `#FFFDF9` | фон, вторинні площини, картки |
| `--ink` / `--ink-2` / `--ink-3` | `#241F2E` / `#5E5670` / `#8E86A0` | текст (теплий сливовий, не чорний) |
| Пастелі: `--lav` `--peach` `--mint` `--butter` `--sky` `--rose` | `#C9B8FF` `#FFC9A9` `#B8F1DC` `#FFE7A3` `#BFE3FF` `#FFC6D9` | заливки чипів, тінти карток, стрічка |
| Глибокі пари `--*-d` | `#6F5BD6` `#D9743F` `#1F8F6E` `#B0781A` `#2C7BB8` `#C24B7A` | текст на пастелі (контраст ≥ 4.5:1) |
| `--grad` | 135°, `#FFB28C → #B29EFF → #78D6BA` | бренд-градієнт: лого, Pro-кнопка, еквалайзер, активний трек |

Правило шести: пастелі призначаються по колу `nth-child(6n+k)` (чипи «Try», сцени, номери треків, теги, bento-тінти). Один елемент = один пастельний колір + його глибока пара для тексту. Primary-кнопка залишається темно-сливовою, щоб пастелі не з'їдали CTA.

## 3. Типографіка
- Display: **Bricolage Grotesque** 600 (заголовки, лого, мітки в uppercase замість mono).
- Акцент: **Fraunces italic** (SOFT 50) для одного словосполучення в заголовку («a sound.»), для цитат «why» і lead-абзацу секції «Why instrumental».
- UI: **Plus Jakarta Sans** 400–700, 16px/1.55.
- Заборонено: mono-шрифти для міток (техно-відчуття), Inter/Roboto.

## 4. Поверхні
- Double-bezel: `.shell-glass` (напівпрозора біла оболонка 45 %, біла рамка, м'яка тепла тінь) + `.core` (папір `#FFFDF9`, внутрішній хайлайт). Тінти `.tint-lav|peach|mint|butter|sky|rose` дають картці м'який кольоровий градієнт зверху.
- `.gborder` — двопіксельна градієнтна рамка тільки для Pro/paywall.
- Spotlight за курсором `[data-spot]` світлий (біле сяйво), не кольоровий.
- Тіні тільки м'які, теплі, з фіолетово-персиковим відтінком; жодних різких чорних.

## 5. Книжковість
- Герой: три **справжні обкладинки** (Google Books) віялом над карткою-зразком, лінія «Now playing», сценний чип.
- Обкладинки завжди з білою рамкою 2px і легким нахилом (−3…−10°), як книжки на столі.
- Полиця бібліотеки: обкладинки-картки з підйомом і нахилом при наведенні.
- Розповідні тексти курсивом Fraunces.

## 6. Кнопки
- `.btn`: темно-сливова пігулка, вкладена кругла стрілка («button-in-button»), sheen, магнітне притягання (fine pointer), пружинний `scale(.96)`.
- `.btn.grad`: бренд-градієнт з темним текстом, лише Pro.
- `.btn-glass`: білі скляні вторинні дії.
- Чипи й сцени: пастельні пігулки, при наведенні піднімаються на 2px і насичуються; активна сцена стає сливовою.

## 7. Композиція
Плаваюча кремова island-навігація (активна вкладка масляно-жовта). Герой-оболонка з пастельним mesh-canvas (лаванда, персик, м'ята, масло, небо) і кремовою вуаллю знизу. Стрічка книг з кольоровими крапками. Bento 7/5 з тінтами. «Why» курсивом + три пастельні картки. Плани: Free кремовий, Pro з градієнтною рамкою. FAQ з лавандовими «+». Фінальний блок із пастельним сяйвом.
Результати: картка книги з лавандовим тінтом, треки з кольоровими номерами, активний трек з лаванда→масло→м'ята градієнтом; док плеєра відкривається **одразу розгорнутим** (відео 500px на десктопі) з клікабельним прогресом, часом і клавіатурним перемотуванням.

## 8. Рух
Вхід: `translateY(20px) + blur(6px)` → 0 за 0.9s. Слова акцентної фрази піднімаються з маски після 300 мс. Пружинна крива `cubic-bezier(.34,1.4,.64,1)` для кнопок/чипів. Атмосфера й marquee повільні, паузуються поза екраном. `prefers-reduced-motion` вимикає все.

## 9. Не робити
Темні теми, mono-шрифти, неонові glow, суцільні сірі рамки, більше двох пастелей в одному елементі, чорні тіні, емодзі як іконки, blur на скролених контейнерах.
