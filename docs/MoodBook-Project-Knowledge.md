## 2. Що таке MoodBook
**MoodBook (moodbook.ink)** — AI-сервіс музичної курації для читачів: генерує інструментальні плейлисти під конкретну книгу. Користувач вводить назву книги → AI аналізує настрій/атмосферу → сервіс видає добірку інструментальних треків для читання під цю книгу.

- Live: `moodbook-six.vercel.app` (цільовий домен `moodbook.ink`)
- GitHub: `portianoi1993/moodbook-`

---

## 3. Технічний стек
- **Frontend:** vanilla JS + HTML + CSS (**без фреймворків** — свідоме рішення, не додавати React тощо).
- **Hosting:** Vercel, serverless-функції в папці `api/`.
- **AI-аналіз книги:** OpenAI GPT-4o-mini.
- **Музика:** YouTube Data API (embeddable інструментальні треки). Раніше був SoundCloud — свідомо відмовились.
- **Метадані книг + автокомпліт:** Google Books API.
- **Безпека:** rate limiting + санітизація інпутів уже додані.
- API-ключі — **тільки через environment variables на Vercel** (`OPENAI_API_KEY`, `YT_API_KEY`), ніколи не хардкодити.

## 6. Immersive-редизайн (`new-design`) — концепція
**Кімната Є інтерфейсом.** Затишний hand-drawn 2D-storybook стиль (Pinterest-рефи: чорні чорнильні контури, теплі землисті flat-кольори, cel shading). Бібліотека-кімната:
- **Стіл по центру** з фізичною книгою = пошук.
- **Ліва стіна = My Library** (збережені книги).
- **Права стіна = Профіль** (метафора corkboard).
- Двоповерхова, галерея-балкон, велике вікно на задній стіні над столом.
- Клік по столу → камера їде згори до книги; вводиш назву → книга **фізично відкривається** двосторінковим розворотом, контент **надрукований на сторінках**.

### Технічно
- Один `index.html`, vanilla JS. Vendored **Three.js r149** (`vendor/three.min.js`) + **CSS3DRenderer** (`vendor/CSS3DRenderer.js`).
- Scene-групи: `architecture / landmarks / atmosphere`. Toon cel-shading (RAMP) + чорнильні контури.
- Камера-риг: keyframes `KF{room, approach, bookTop, library, profile}` + `goTo(state)` з timed tween.
- Книга: 3D-меші (`closedBook` / `openBook` групи) + **CSS3D-контент** (`coverObj` пошук, `spreadObj` розворот) що лежить на книзі.
- Реальний пошук через ті самі serverless-функції: `api/claude.js` (identify/tracks/moods) + `api/search.js` (YouTube videoId).
- Debug-хендл: `window.MOODBOOK = {goTo, rig, KF, renderer, scene, camera, cssRenderer, cssScene, APP, SFX, setMode, toggleMode, curEnv, book:{...}}`.

### Готово на прев'ю (гілка new-design)
- Двоповерхова симетрична бібліотека, **стіл по центру на килимі**, торшер праворуч біля столу, два вікна.
- **Day/Night** через клік по торшеру: справжній environmental transition (sun/ambient/fog/фон/вікна/зорі/лампи), не булеан.
- **Фізична книга**: закрита книга з пошуком → відкривається розворотом (треклист зліва, настрій/жанр справа), контент надрукований на кремових сторінках, **пропорційний до столу** (не стирчить), камера кадрує стіл+книгу разом.
- **Центральний баг виправлено:** `renderer.setSize(w,h,false)` на HiDPI (DPR>1) робив канвас більшим за вікно → стіл зміщувався, CSS/WebGL не збігались, кліки мимо. Фікс: `renderer.setSize(w,h)` (updateStyle=true).
- Прибрано паралакс (стіл мертво по центру, кліки збігаються).
- Централізована аудіо-система `SFX.play('page-turn'|'purr'|'pop'|'lamp')` — файлів ще нема (тихі заглушки), підключаються через `SFX.set(name, 'assets/sfx/x.mp3')`.

### Залишилось (за повним брифом власника)
1. **My Library** (ліві полиці): збережені книги, назви на корінцях, клік по книзі → камера до столу → книга відкривається з ТИМ треклистом. Модель: localStorage → потім Supabase.
2. **Corkboard-профіль** (права стіна): коркова дошка з реальними даними акаунта (ім'я, avatar, підписка, дата реєстрації, статистика).
3. **Кіт-пасхалка**: спляча кішка на полиці, ледь помітне дихання, клік → `SFX.play('purr')`. Не навігація.
4. **Рослини / дрібні об'єкти** на полицях (~80–90% книг лишити).
5. **Intro-лого MoodBook**: cloudy-graffiti «Mood»(біле)+«Book»(пастель) над столом, м'яка поява + `SFX.play('pop')`.
6. **Аудіо-файли**: власник надасть фінальні звуки → кинути в `assets/sfx/` і підключити через `SFX.set`.
7. **Фаза 4 — арт-стиль**: довести вигляд до hand-drawn Pinterest-рефів (генерація плейтів через OpenAI `gpt-image-1`, власним ключем власника).
