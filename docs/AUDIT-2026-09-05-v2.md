## 2. Що зроблено у v2

### Бекенд (`api/`, `lib/`)
- **`GET /api/analyze`** — один виклик AI замість двох: повертає `book` (назва, автор, жанр, сеттінг, тон), `why` (речення про звукову ідею), `moods[6]`, `tracks[6]`. JSON-режим (`response_format`) з автоматичним фолбеком, таймаут 25 с, валідація відповіді, in-memory кеш 24 год + CDN-кеш 7 днів (`s-maxage`). Повторний пошук тієї ж книги = 0 звернень до OpenAI.
- **Провайдер-агностичний AI**: `AI_API_KEY` (або старий `OPENAI_API_KEY`), `AI_BASE_URL`, `AI_MODEL`. Працює з OpenAI, OpenRouter, **OmniRoute** або будь-яким OpenAI-сумісним ендпоінтом. Помилка апстріму тепер повертається як `detail` (статус + текст), а не ковтається.
- **`GET /api/books`** — проксі Google Books: ключ лише на сервері, ранжування (збіг із запитом, автор, обкладинка, мова, штраф за summary/workbook/ALL-CAPS-підробки), чистка назв від «(Deluxe Edition)», CDN-кеш 24 год. Режим `best=1` для визначення книги. Українські запити («Дюна») повертають українське видання.
- **`GET /api/search`** — YouTube без захардкодженого ключа; фільтри `videoEmbeddable`, `videoSyndicated`, `videoDuration=long`; ранжування за переглядами й тривалістю (≥1 год), блок-лист «lyrics/karaoke/vocal», декодування HTML-сутностей, 3 альтернативи на випадок відмови відео. CDN-кеш 24 год.
- **`GET /api/health`** та **`/api/health?probe=1`** — показує, які env-змінні задані, і робить тестовий виклик AI, повертаючи справжню відповідь апстріму. Це відповідь на питання «чому 502».
- `lib/http.js` — спільні rate-limit/CORS/кеш/таймаут. `vercel.json` переведено з legacy `routes` на `rewrites` + `headers` (no-store для HTML, кеш для статики, security-заголовки).

### Фронтенд (`index.html`, `css/app.css`, `js/app.js`)
- **Адаптивність з нуля (mobile-first)**: на телефоні — нижня панель вкладок із safe-area, на планшеті/десктопі — верхні вкладки; результати на десктопі у 2 колонки (книга + сцени зліва, треки справа), на мобільному — книга → треки → сцени.
- **Постійний плеєр-док** через YouTube IFrame API: play/pause, next/prev, прогрес, авто-перехід на наступний трек, розгортання відео (дотримання мінімального розміру плеєра). Музика не обривається при зміні сцени чи вкладки.
- **Пошук**: комбобокс з клавіатурною навігацією, статуси етапів («Identifying the book…», «Composing…»), скелетони, inline-помилка з «Try again» і текстом причини, prefetch перших двох треків.
- **Картка книги** з обкладинкою, тегами (жанр/сеттінг/тон) і фразою «чому саме такий саундтрек».
- **Deep-link і шеринг**: `/?b=Dune` відкриває пошук одразу; кнопка Share (Web Share API / копіювання) — перший крок до «Reading Card».
- **Free-ліміт застосований**: 3 пошуки на день, лічильник у героі, м'який paywall із промокодом. Константа `FREE_DAILY_LIMIT` в `js/app.js`.
- **Бібліотека**: shelf-grid, автокомпліт при додаванні, «Undo» при видаленні, лайки з відтворенням.
- **Акаунт**: чесна економіка (17% знижка), «Request early access» замість фейкового платежу, промокод.
- **Доступність/якість**: семантичні лендмарки, skip-link, `aria-*`, `:focus-visible`, `prefers-reduced-motion`, лише `transform/opacity` в анімаціях, 16px базовий текст, контрастні кольори, OG/favicon/manifest/theme-color, логотип 7 KB замість 368 KB.
- Дані користувачів (`mb_books`, `mb_liked_tracks`, `mb_pro`) **сумісні** зі старою версією — нічого не втрачається.

### Dev-інструменти
- `npm run dev` (`scripts/dev.mjs`) — локальний сервер, який монтує `api/*.js` як Vercel; ключі з `.env.local` (у `.gitignore`).
- `scripts/mock-ai.mjs` — мок OpenAI-сумісного сервера для UI-тестів без ключа.

## 2b. Безкоштовна AI-архітектура (додано того ж дня)

Причина 502 на проді: **на OpenAI закінчились кредити**. Замість поповнення v2 переходить на безкоштовні провайдери:

| Роль | Провайдер | Модель | Ліміт free-tier | Де взяти ключ |
|------|-----------|--------|-----------------|---------------|
| Основний | Google Gemini | `gemini-2.5-flash` | ~1500 запитів/день, без картки | aistudio.google.com → Get API key |
| Запасний | Groq | `llama-3.3-70b-versatile` | ~14 400 запитів/день, без картки | console.groq.com → API Keys |
| Запасний 2 (опційно) | OpenRouter | `…:free` моделі | 50/день без депозиту | openrouter.ai/keys |

`lib/ai.js` пробує провайдерів по черзі (429/помилка/таймаут → наступний). Кеш у пам'яті та на CDN означає, що одна книга = один запит на тиждень. Якщо всі мовчать, `lib/fallback.js` збирає плейлист за жанром (UI показує позначку «matched by genre»). Сервіс більше ніколи не показує помилку замість музики.

YouTube Data API також безкоштовний: 10 000 одиниць/день ≈ 100 пошуків треків/день (кеш 24 год зменшує витрату). Якщо стане тісно, у Google Cloud подається безкоштовна форма на збільшення квоти.

## 2c. Статус на кінець дня 5 вересня
- Gemini free tier **працює на превʼю**: `gemini-2.5-flash` знято з нових користувачів, код сам мігрував на `gemini-3.6-flash` (авто-міграція в `lib/ai.js`). Реальна відповідь для «Fourth Wing»: Romantic Fantasy, Basgiath War College, треки «Crossing the Parapet», «Golden Eyes of Tairn»…
- Редизайн «Reading room» задеплоєно на превʼю (див. `docs/DESIGN.md`): лендинг (герой зі зразком картки, як працює, чому інструментал, плани, FAQ, фінальний CTA), сторінки Privacy/Terms, футер.
- У Google Cloud (проєкт «My First Project») створено новий ключ «MoodBook server (YouTube + Books)», обмежений двома API. Залишилось вставити його у Vercel як `YT_API_KEY` і передеплоїти.

## 3. Що потрібно від власника перед мержем у `main`

1. **Безкоштовний AI.** Отримати ключі Gemini і Groq (без картки) і додати у Vercel: `AI_API_KEY`, `AI_BASE_URL`, `AI_MODEL`, `AI_FALLBACK_API_KEY`, `AI_FALLBACK_BASE_URL`, `AI_FALLBACK_MODEL` (Production + Preview). Стару `OPENAI_API_KEY` видалити. Перевірка: `/api/health?probe=1` має показати `ok:true` хоча б для одного провайдера.
2. **Ротація Google-ключа.** Старий ключ публічний у git-історії. У Google Cloud Console: створити новий ключ, обмежити його API (Books + YouTube Data), встановити як `YT_API_KEY` (і за бажанням окремий `GOOGLE_BOOKS_KEY`) на Vercel, старий — видалити.
3. Перевірити превʼю гілки `v2` на телефоні й десктопі, потім `git merge v2` у `main`.

## 4. Скіли, застосовані під час роботи, і що з них узято

| Скіл | Що дав проєкту |
|------|----------------|
| `frontend-design` | Один чіткий напрям (теплий «папір» + чорнило + peach→teal), реальні стани (loading/empty/error), self-review на mobile+desktop. |
| `web-design-guidelines` (Vercel) | Чекліст: aria-label на іконках, `:focus-visible`, `prefers-reduced-motion`, без `transition:all`, `min-width:0` для обрізання тексту, URL відображає стан, Undo замість миттєвого видалення, safe-area. |
| `emil-design-eng` | Тайминги/кривʼі (`cubic-bezier(.23,1,.32,1)`, ≤300 мс), `scale(.97)` на натисканні, поява елементів не з `scale(0)`, транзишени замість keyframes для інтерфейсу. |
| `cro` | Ціннісна пропозиція у першому екрані, конкретний CTA («Request early access»), лічильник ліміту як мʼякий тригер, чесна ціна. |
| `stop-slop` | Копірайт без «AI-штампів»: короткі речення, друга особа, конкретика. |
| `seo-audit` / `schema` (частково) | Title/description/OG/manifest/robots, семантика заголовків. Наступний крок — JSON-LD `WebApplication` і лендинг-контент. |
| `task-observer` | 2 спостереження записано (перевіряти прод перед редизайном; вимикати транзишени під час скриншот-верифікації). |

**OmniRoute.** Встановлений локально (`omniroute` 3.8.49, порт 20128) — це OpenAI-сумісний шлюз до 160+ провайдерів із безкоштовними тарифами. Для **продакшену на Vercel** він не підходить напряму (працює на вашому ПК), але тепер бекенд MoodBook налаштовується під нього одним env: `AI_BASE_URL=http://<host>:20128/v1`. Сценарії: (а) локальна розробка й тестування промптів безкоштовно; (б) якщо колись розгорнете OmniRoute на VPS — миттєве перемикання проду без зміни коду; (в) економія на Claude Code, якщо пустити його через OmniRoute (це поза кодом MoodBook).

## 5. Roadmap далі (пріоритети)

1. **Supabase**: auth + синхронізація `mb_books/mb_liked_tracks` + серверні промокоди (замість масиву в JS) + справжній ліміт по користувачу, а не по браузеру.
2. **Reading Card**: `/api/og?b=...` (Vercel OG image) — картинка обкладинка+3 треки для шерингу в Reddit/TikTok. Кнопка Share уже готова під це.
3. **Лендинг для SEO/AI-SEO**: FAQ, «soundtrack for X» програмні сторінки (`programmatic-seo`), JSON-LD.
4. **WayForPay** після ФОП — `api/pay.js` з підписом на сервері, ніколи з фронтенду.
5. Аналітика подій (пошук, play, like, paywall) — мінімально через Vercel Analytics або Plausible.
